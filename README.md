Lord Veylan, usurper of Aldermere, has the crown, the relic, and your rebellion's names — spelled correctly, mostly. A 101-word monologue where the tiredness leaks through the voice instead of being announced.

## Run it

```bash
python3 main.py
```

This writes the monologue to `/output/entry.txt`, byte-identical on every run.
